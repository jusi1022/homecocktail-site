Matcha Cream Cocktail

  • 약한 술
  • 부드러움

재료와 분량

  • 말차말차파우더 1 tsp + 뜨거운 물 90ml 섞고 식힌 것을 사용60 ml
  • 바닐라 보드카45 ml
  • 심플 시럽제품명 카나두(사탕수수 설탕 시럽)22.5 ml
  • 오트 밀크45 ml
  • 생크림[말차 크림] 토핑 하위 레시피40 ml
  • 우유[말차 크림] 토핑 하위 레시피20 ml
  • 심플 시럽[말차 크림] 토핑 하위 레시피10 ml
  • 말차[말차 크림] 토핑 하위 레시피15 ml
  • 생크림플로팅; 아래 [말차 크림] 하위 레시피로 만든 것
  • 말차플로팅

만드는 법

  1. [말차 크림] 믹싱글라스에 휘핑 크림 40ml, 우유 20ml, 카나두 시럽 10ml를 넣고 휘핑합니다
  2. [말차 크림] 말차 15ml를 넣고 한 번 더 휘핑해 둡니다
  3. 쉐이커에 얼음을 넣습니다
  4. 말차 60ml, 바닐라 보드카 45ml, 카나두 시럽 22.5ml, 오트 밀크 45ml를 넣습니다
  5. 쉐이킹 후 칵테일 잔에 따릅니다
  6. 휘핑한 말차 크림을 위에 띄웁니다
  7. 말차 파우더를 위에 뿌립니다
