레몬 드롭 마티니

Lemon Drop Martini

보드카에 트리플 섹과 레몬을 더한 상큼한 마티니 형식.

  • 상큼함

재료와 분량

  • 보드카30 ml
  • 트리플 섹20 ml
  • 레몬즙15 ml

만드는 법

  1. 셰이커에 재료와 얼음을 넣습니다.
  2. 충분히 흔듭니다.
  3. 차갑게 준비한 잔에 걸러 따릅니다.

출처: Difford's Guide

Difford's Guide · Lemon Drop Martini

Difford's Guide에 실린 레시피예요. 기본 레시피와 재료나 분량이 달라요.

  • 달콤함
  • 상큼함
  • 시트러스

시트론 보드카에 레몬즙과 리치 슈거 시럽을 더한 칵테일이에요. Difford's Guide 분류로는 사워·시트러스 스타일이고, 재료로 보면 단맛이 예상돼요.

맛 표시는 원문(Difford's Guide)의 분류와 재료 기반 예상 맛을 함께 정리한 참고 정보이며, 직접 맛본 평가가 아닙니다.

재료와 분량

  • 시트론 보드카60 ml
  • 트리플 섹7.5 ml
  • 레몬즙22.5 ml
  • 리치 슈거 시럽(설탕 2:물 1)15 ml
  • 식염수(소금 20g : 물 80g)직접 만드는 재료 · 재료: 소금, 물3 방울

만드는 법

  1. 마티니 잔을 미리 차갑게 준비합니다.
  2. 가니시로 레몬 제스트 트위스트를 준비합니다.
  3. 모든 재료를 얼음과 함께 셰이크합니다.
  4. 차갑게 한 잔에 고운 체로 걸러 따릅니다(파인 스트레인).
  5. 레몬 제스트 트위스트의 오일을 칵테일 위에 뿌리고 가니시로 올립니다.
