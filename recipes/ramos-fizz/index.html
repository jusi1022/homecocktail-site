어쿠스틱 드링크 영상의 비율이에요. 기본 레시피(라모스 피즈)와 재료나 분량이 달라요.

재료와 분량

  • 진15 ml
  • 레몬즙15 ml
  • 라임즙15 ml
  • 심플 시럽30 ml
  • 생크림60 ml
  • 달걀 흰자1 개

만드는 법

  1. 쉐이커에 재료(얼음 없이) → 얼음 넣어 쉐이킹
  2. 믹싱 글라스에 걸러 거품을 낸다
  3. 하이볼 잔에 탄산수 조금, 칵테일을 붓고 3분 대기 후 나머지와 탄산수 보충
  4. 잘 서는 빨대

  • 나만의 레시피와 즐겨찾기 — 집에서 만든 칵테일을 내 레시피로 저장하고, 마음에 드는 칵테일을 즐겨찾기에 담아 둡니다.
